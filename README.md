# StudyMate

مشروع ويب عربي لتنظيم المذاكرة.

## تشغيل المشروع
افتح ملف `index.html` في المتصفح. يحتاج اتصالًا بالإنترنت لتحميل خط Cairo من Google Fonts؛ وسيعمل بخط بديل إذا لم يتوفر الاتصال.

## هيكل الملفات
- `index.html`
- `css/index.css`
- `js/data.js`
- `js/index.js`

## ملاحظة
يحفظ الموقع بيانات الملف الدراسي والدروس والمهام ووقت المذاكرة محليًا في المتصفح باستخدام `localStorage`. البيانات لا تنتقل تلقائيًا بين الأجهزة أو المتصفحات.
